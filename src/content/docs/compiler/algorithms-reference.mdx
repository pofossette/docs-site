## 1. 词法分析：子集构造法（NFA 转 DFA）制表全推导

### 【原始题目】
给定正则表达式 $r = (a \mid b)^*ab$，使用 Thompson 算法构造 NFA 后，使用**子集构造法（Subset Construction）** 将其转换为等价的确定性有限自动机（DFA），并写出完整的状态转换表。

---

### 【第一步：绘制 Thompson NFA】
根据 Thompson 构造规则，展开 $(a \mid b)^*ab$ 得到如下 10 个状态（编号 $0 \sim 9$）：
* 状态 $0$：初态
* 状态 $0 \xrightarrow{\epsilon} 1, \; 0 \xrightarrow{\epsilon} 7$
* 状态 $1 \xrightarrow{\epsilon} 2, \; 1 \xrightarrow{\epsilon} 4$
* 状态 $2 \xrightarrow{a} 3, \; 4 \xrightarrow{b} 5$
* 状态 $3 \xrightarrow{\epsilon} 6, \; 5 \xrightarrow{\epsilon} 6$
* 状态 $6 \xrightarrow{\epsilon} 1, \; 6 \xrightarrow{\epsilon} 7$
* 状态 $7 \xrightarrow{a} 8 \xrightarrow{b} 9$（状态 $9$ 为双圈终态）

---

### 【第二步：子集构造法完整填表过程】

定义运算：
1. $\epsilon\text{-closure}(s)$：从状态 $s$ 出发，仅通过 $\epsilon$ 弧能到达的所有状态集合（包含 $s$ 自身）。
2. $\text{move}(I, a)$：集合 $I$ 中所有状态吃进字符 $a$ 后直接到达的状态集合。

#### 1. 计算初始状态子集 A：
$$I_0 = \epsilon\text{-closure}(0) = \{0, 1, 2, 4, 7\} \implies \text{记为状态 } A$$
*注：$0 \xrightarrow{\epsilon} 1 \xrightarrow{\epsilon} 2, 4$；$0 \xrightarrow{\epsilon} 7$。*

#### 2. 从状态 A 出发：
* **输入 $a$**：
  * 状态 $2 \xrightarrow{a} 3$；状态 $7 \xrightarrow{a} 8$。
  * $\text{move}(A, a) = \{3, 8\}$。
  * 求闭包：$\epsilon\text{-closure}(\{3, 8\})$：
    * 从 $3$ 出发可到 $6 \xrightarrow{\epsilon} 1 \xrightarrow{\epsilon} 2, 4$；$6 \xrightarrow{\epsilon} 7$。
    * 从 $8$ 出发无 $\epsilon$ 弧。
    * 得到集合 $\{1, 2, 3, 4, 6, 7, 8\}$ $\implies$ **全新状态，记为 B**。
* **输入 $b$**：
  * 状态 $4 \xrightarrow{b} 5$。
  * $\text{move}(A, b) = \{5\}$。
  * 求闭包：$\epsilon\text{-closure}(\{5\}) = \{1, 2, 4, 5, 6, 7\}$ $\implies$ **全新状态，记为 C**。

#### 3. 考察状态 B（包含 $\{1, 2, 3, 4, 6, 7, 8\}$）：
* **输入 $a$**：
  * 能吃 $a$ 的有 $2 \to 3$ 和 $7 \to 8$。
  * $\text{move}(B, a) = \{3, 8\}$。
  * $\epsilon\text{-closure}(\{3, 8\}) = \{1, 2, 3, 4, 6, 7, 8\} \implies$ **正是状态 B 自己！**
* **输入 $b$**：
  * 能吃 $b$ 的有 $4 \to 5$ 和 $8 \to 9$（注意：$9$ 是终态！）。
  * $\text{move}(B, b) = \{5, 9\}$。
  * 求闭包：从 $5$ 出发到 $\{1, 2, 4, 5, 6, 7\}$；从 $9$ 出发无 $\epsilon$。
  * 得到集合 $\{1, 2, 4, 5, 6, 7, 9\}$ $\implies$ **全新状态，包含终态 9，记为 D（终态）**。

#### 4. 考察状态 C（包含 $\{1, 2, 4, 5, 6, 7\}$）：
* **输入 $a$**：
  * 能吃 $a$ 的有 $2 \to 3$ 和 $7 \to 8$。
  * $\text{move}(C, a) = \{3, 8\} \implies \epsilon\text{-closure} = B$。
* **输入 $b$**：
  * 能吃 $b$ 的有 $4 \to 5$。
  * $\text{move}(C, b) = \{5\} \implies \epsilon\text{-closure} = C$。

#### 5. 考察状态 D（包含 $\{1, 2, 4, 5, 6, 7, 9\}$，终态）：
* **输入 $a$**：
  * 能吃 $a$ 的有 $2 \to 3$ 和 $7 \to 8$。
  * $\text{move}(D, a) = \{3, 8\} \implies \epsilon\text{-closure} = B$。
* **输入 $b$**：
  * 能吃 $b$ 的有 $4 \to 5$。
  * $\text{move}(D, b) = \{5\} \implies \epsilon\text{-closure} = C$。

---

### 【第三步：最终 DFA 转换表】

| DFA 状态 | 包含 NFA 状态集合 | 输入 $a$ | 输入 $b$ | 是否为终态 |
| :---: | :--- | :---: | :---: | :---: |
| **A (初态)** | $\{0, 1, 2, 4, 7\}$ | **B** | **C** | 否 |
| **B** | $\{1, 2, 3, 4, 6, 7, 8\}$ | **B** | **D** | 否 |
| **C** | $\{1, 2, 4, 5, 6, 7\}$ | **B** | **C** | 否 |
| **D (终态)** | $\{1, 2, 4, 5, 6, 7, 9\}$ | **B** | **C** | **是 (含9)** |

## 2. 词法分析：Hopcroft 划分法（DFA 状态最小化）全演算

### 【原始题目】
针对上述第 1 题生成的 DFA（状态为 $A, B, C, D$，其中 $D$ 为终态），使用 Hopcroft 划分算法进行最小化化简，验证其是否存在冗余等价状态。

---

### 【第一步：初始划分】
根据是否为终态，将状态集 $\{A, B, C, D\}$ 划分为两个初始子集：
$$\Pi_0 = \{ G_1, \; G_2 \}$$
* $G_1 = \{A, B, C\}$（非终态组）
* $G_2 = \{D\}$（终态组，单元素，不可再分）

---

### 【第二步：考察组内区分度】

我们对 $G_1 = \{A, B, C\}$ 中的每个状态，测试输入符号 $\{a, b\}$ 的跳转目标：

1. **测试输入 $a$**：
   * $A \xrightarrow{a} B \in G_1$
   * $B \xrightarrow{a} B \in G_1$
   * $C \xrightarrow{a} B \in G_1$
   * **结论**：在输入 $a$ 下，三者都跳入 $G_1$，无法区分。

2. **测试输入 $b$**：
   * $A \xrightarrow{b} C \in G_1$
   * $B \xrightarrow{b} D \in \mathbf{G_2}$（注意！$B$ 跳向了另一个组 $G_2$！）
   * $C \xrightarrow{b} C \in G_1$
   * **结论**：$B$ 的行为与 $A, C$ 产生分歧！$B$ 必须被单独分裂出去！

于是，划分更新为：
$$\Pi_1 = \{ \{A, C\}, \; \{B\}, \; \{D\} \}$$

---

### 【第三步：继续考察 $\{A, C\}$】
对组 $\{A, C\}$ 再次测试输入 $\{a, b\}$：
* **输入 $a$**：$A \xrightarrow{a} B \in \{B\}$；$C \xrightarrow{a} B \in \{B\}$（目标一致）
* **输入 $b$**：$A \xrightarrow{b} C \in \{A, C\}$；$C \xrightarrow{b} C \in \{A, C\}$（目标一致）
* **结论**：无论给什么输入，$A$ 与 $C$ 的跳转归宿完全相同，**$A$ 与 $C$ 是完全等价状态，可以合并！**

---

### 【第四步：输出最简 DFA】
将 $A$ 与 $C$ 合并为新状态 $AC$（初态）：
* $AC \xrightarrow{a} B, \quad AC \xrightarrow{b} AC$
* $B \xrightarrow{a} B, \quad B \xrightarrow{b} D$
* $D \xrightarrow{a} B, \quad D \xrightarrow{b} AC$（$D$ 为终态）

状态数由原本的 4 个精简为 **3 个状态**！

## 3. 语法分析：LL(1) 全流程（左递归消除 + FIRST/FOLLOW + 分析表 + 17步分析栈推导）

### 【原始题目】
给定经典算术表达式文法 $G[E]$：
$$E \to E + T \mid T$$
$$T \to T * F \mid F$$
$$F \to ( E ) \mid \mathbf{id}$$

要求：
1. 消除文法的左递归；
2. 计算所有非终结符的 $\text{FIRST}$ 与 $\text{FOLLOW}$ 集合；
3. 构造 LL(1) 预测分析表；
4. 给出对输入串 $\mathbf{id} + \mathbf{id} * \mathbf{id}$ 的完整分析栈匹配过程。

---

### 【第一步：消除直接左递归】
文法中 $E$ 和 $T$ 均含有直接左递归，引入新非终结符 $E'$ 和 $T'$：
1. $E \to T E'$
2. $E' \to + T E' \mid \epsilon$
3. $T \to F T'$
4. $T' \to * F T' \mid \epsilon$
5. $F \to ( E ) \mid \mathbf{id}$

非终结符集合 $V_N = \{E, E', T, T', F\}$  
终结符集合 $V_T = \{+, *, (, ), \mathbf{id}\}$，句子结束符为 $\$$。

---

### 【第二步：严格计算 FIRST 集合】

* **计算 $\text{FIRST}(F)$**：
  * 产生式 $F \to ( E ) \mid \mathbf{id}$
  * 直接得到：$\text{FIRST}(F) = \{ (, \; \mathbf{id} \}$
* **计算 $\text{FIRST}(T')$**：
  * 产生式 $T' \to * F T' \mid \epsilon$
  * 直接得到：$\text{FIRST}(T') = \{ *, \; \epsilon \}$
* **计算 $\text{FIRST}(T)$**：
  * 产生式 $T \to F T'$，由于 $F$ 不能推导出 $\epsilon$，因此 $\text{FIRST}(T) = \text{FIRST}(F) = \{ (, \; \mathbf{id} \}$
* **计算 $\text{FIRST}(E')$**：
  * 产生式 $E' \to + T E' \mid \epsilon$
  * 直接得到：$\text{FIRST}(E') = \{ +, \; \epsilon \}$
* **计算 $\text{FIRST}(E)$**：
  * 产生式 $E \to T E'$，由于 $T$ 不能推导出 $\epsilon$，因此 $\text{FIRST}(E) = \text{FIRST}(T) = \{ (, \; \mathbf{id} \}$

---

### 【第三步：严格计算 FOLLOW 集合】

* **计算 $\text{FOLLOW}(E)$**：
  * $E$ 是开始符号，首先将输入终止符 `#` 放入：
    $$\text{FOLLOW}(E) = \{ \# \}$$

  * 观察产生式中 $E$ 出现的位置：$F \to ( E )$，后面跟着括号 `)`，将 `)` 加入：
    $$\text{FOLLOW}(E) = \{ ), \; \# \}$$
* **计算 $\text{FOLLOW}(E')$**：
  * 观察产生式：$E \to T E'$，由于 $E'$ 位于末尾，把 $\text{FOLLOW}(E)$ 传给 $\text{FOLLOW}(E')$；
  * 产生式 $E' \to + T E'$ 也位于末尾；
  * 因此：$$\text{FOLLOW}(E') = \text{FOLLOW}(E) = \{ ), \; \# \}$$
* **计算 $\text{FOLLOW}(T)$**：
  * 观察产生式 $E \to T E'$ 和 $E' \to + T E'$：
    * $T$ 后面跟着 $E'$，将 $\text{FIRST}(E') \setminus \{\epsilon\} = \{ + \}$ 加入；
    * 又因为 $E' \Rightarrow^* \epsilon$，必须把 $\text{FOLLOW}(E')$ 也传给 $\text{FOLLOW}(T)$；
  * 综上：$$\text{FOLLOW}(T) = \{ +, \; ), \; \# \}$$
* **计算 $\text{FOLLOW}(T')$**：
  * 观察产生式 $T \to F T'$，因为 $T'$ 位于末尾，把 $\text{FOLLOW}(T)$ 传给 $\text{FOLLOW}(T')$；
  * 综上：$$\text{FOLLOW}(T') = \text{FOLLOW}(T) = \{ +, \; ), \; \# \}$$
* **计算 $\text{FOLLOW}(F)$**：
  * 观察产生式 $T \to F T'$ 和 $T' \to * F T'$：
    * $F$ 后面跟着 $T'$，将 $\text{FIRST}(T') \setminus \{\epsilon\} = \{ * \}$ 加入；
    * 又因为 $T' \Rightarrow^* \epsilon$，必须把 $\text{FOLLOW}(T')$ 也传给 $\text{FOLLOW}(F)$；
  * 综上：$$\text{FOLLOW}(F) = \{ *, \; +, \; ), \; \# \}$$

---

### 【第四步：构造 LL(1) 预测分析表】

填表规则：
1. 对于产生式 $A \to \alpha$，对每一个 $a \in \text{FIRST}(\alpha)$，将 $A \to \alpha$ 填入 $M[A, a]$；
2. 若 $\epsilon \in \text{FIRST}(\alpha)$，则对每一个 $b \in \text{FOLLOW}(A)$，将 $A \to \alpha$ 填入 $M[A, b]$。

| 非终结符 | $\mathbf{id}$ | $+$ | $*$ | $($ | $)$ | $\$$ |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **$E$** | $E \to T E'$ | | | $E \to T E'$ | | |
| **$E'$** | | $E' \to + T E'$ | | | $E' \to \epsilon$ | $E' \to \epsilon$ |
| **$T$** | $T \to F T'$ | | | $T \to F T'$ | | |
| **$T'$** | | $T' \to \epsilon$ | $T' \to * F T'$ | | $T' \to \epsilon$ | $T' \to \epsilon$ |
| **$F$** | $F \to \mathbf{id}$ | | | $F \to ( E )$ | | |

*每个格点最多仅有一条产生式，**严格证明该文法是无二义性、无冲突的 LL(1) 文法**！*

---

### 【第五步：输入串 `id + id * id` 的分析栈推导全轨迹】

| 步骤 | 符号分析栈（栈底在左，栈顶在右） | 当前剩余输入串 | 所选动作 / 所用产生式 |
| :---: | :--- | :--- | :--- |
| 1 | `# E` | `id + id * id #` | 查 $M[E, \text{id}]$：用 $E \to T E'$ 展开 |
| 2 | `# E' T` | `id + id * id #` | 查 $M[T, \text{id}]$：用 $T \to F T'$ 展开 |
| 3 | `# E' T' F` | `id + id * id #` | 查 $M[F, \text{id}]$：用 $F \to \text{id}$ 展开 |
| 4 | `# E' T' id` | `id + id * id #` | **匹配终结符 id**，弹出栈顶，指针前移 |
| 5 | `# E' T'` | `+ id * id #` | 查 $M[T', +]$：用 $T' \to \epsilon$（弹出 $T'$） |
| 6 | `# E'` | `+ id * id #` | 查 $M[E', +]$：用 $E' \to + T E'$ 展开 |
| 7 | `# E' T +` | `+ id * id #` | **匹配终结符 +**，弹出栈顶，指针前移 |
| 8 | `# E' T` | `id * id #` | 查 $M[T, \text{id}]$：用 $T \to F T'$ 展开 |
| 9 | `# E' T' F` | `id * id #` | 查 $M[F, \text{id}]$：用 $F \to \text{id}$ 展开 |
| 10 | `# E' T' id` | `id * id #` | **匹配终结符 id**，弹出栈顶，指针前移 |
| 11 | `# E' T'` | `* id #` | 查 $M[T', *]$：用 $T' \to * F T'$ 展开 |
| 12 | `# E' T' F *` | `* id #` | **匹配终结符 \***，弹出栈顶，指针前移 |
| 13 | `# E' T' F` | `id #` | 查 $M[F, \text{id}]$：用 $F \to \text{id}$ 展开 |
| 14 | `# E' T' id` | `id #` | **匹配终结符 id**，弹出栈顶，指针前移 |
| 15 | `# E' T'` | `#` | 查 $M[T', \#]$：用 $T' \to \epsilon$（弹出 $T'$） |
| 16 | `# E'` | `#` | 查 $M[E', \#]$：用 $E' \to \epsilon$（弹出 $E'$） |
| 17 | `#` | `#` | **栈底与输入界符重合，分析成功 ACCEPT！** |

## 4. 语法分析：LR(0) / SLR(1) 项目集规范族构建与冲突消解全过程

### 【原始题目】
给定拓广文法 $G'[S]$：
- (0) $S' \to S$
- (1) $S \to a A c$
- (2) $S \to b A d$
- (3) $A \to b$

要求：构造其 LR(0) 项目集规范族（DFA），判断是否存在冲突；若存在，说明 SLR(1) 能否解决该冲突。

---

### 【第一步：构造 LR(0) 项目集族与闭包演算】

#### 状态 $I_0$：
* 初项：$[S' \to \cdot S]$
* 圆点后是 $S$，引入 $S$ 的所有产生式：
  * $[S \to \cdot a A c]$
  * $[S \to \cdot b A d]$
* **$I_0 = \{ [S' \to \cdot S], \; [S \to \cdot a A c], \; [S \to \cdot b A d] \}$**

#### 计算转移：
* **$\text{GOTO}(I_0, S) = I_1$**：
  * $\{ [S' \to S \cdot] \}$ $\implies$ **接受态 ACC**。
* **$\text{GOTO}(I_0, a) = I_2$**：
  * $\{ [S \to a \cdot A c] \}$
  * 圆点后是 $A$，求闭包引入 $A \to \cdot b$：
  * **$I_2 = \{ [S \to a \cdot A c], \; [A \to \cdot b] \}$**
* **$\text{GOTO}(I_0, b) = I_3$**：
  * 从 $[S \to \cdot b A d]$ 移进 $b$，得到 $[S \to b \cdot A d]$；圆点后是 $A$，引入 $[A \to \cdot b]$；
  * 注意在 $I_0$ 中，如果直接接收 $b$ 作为产生式 (3) $A \to b$ 的归约前缀：
    * 状态中同时包含了 $[S \to b \cdot A d]$（移进项）
    * 以及 $[A \to b \cdot]$（圆点在末尾，归约项！）
  * **$I_3 = \{ [S \to b \cdot A d], \; [A \to \cdot b], \; [A \to b \cdot] \}$**

---

### 【第二步：LR(0) 冲突检测】
观察状态 $I_3$：
* 项目 $[S \to b \cdot A d]$：面对输入符号 $b$ 可以继续**移进（Shift）**；
* 项目 $[A \to b \cdot]$：无论输入什么，它都想按照产生式 (3) **归约（Reduce）**！
* **致命结论**：在状态 $I_3$ 中，同时存在移进动作和归约动作，且**没有展望符**帮助区分，发生了严重的 **移进-归约冲突（Shift-Reduce Conflict）**！因此该文法**绝不是 LR(0) 文法**！

---

### 【第三步：SLR(1) 能否消解该冲突？】

SLR(1) 的思想是：**只有当面临的输入符号属于待归约符号的 $\text{FOLLOW}$ 集合时，才允许执行归约动作！**

1. **计算待归约符号 $A$ 的 $\text{FOLLOW}(A)$ 集合**：
   * 观察文法产生式：
     * $S \to a A c \implies c \in \text{FOLLOW}(A)$
     * $S \to b A d \implies d \in \text{FOLLOW}(A)$
   * 得到：$$\text{FOLLOW}(A) = \{ c, \; d \}$$
2. **考察状态 $I_3$ 的移进符号集合**：
   * 在状态 $I_3$ 中，可以移进的符号是产生式 $[A \to \cdot b]$ 中的终结符 $\{ b \}$。
3. **求交集判定**：
   $$\{ c, d \} \cap \{ b \} = \emptyset$$
   **交集为空！**
4. **终极结论**：
   * 当在状态 $I_3$ 下看到下一个字符是 **`b`** 时，绝对执行**移进**；
   * 当看到下一个字符是 **`c` 或 `d`** 时，才执行**归约 $A \to b$**；
   * 冲突被 SLR(1) 完美化解！该文法是合法的 **SLR(1) 文法**！

## 5. 语义与中间代码：布尔表达式拉链与回填（Backpatching）四元式推导

### 【原始题目】
针对经典控制流语句：
```c
if (a < b && c < d) 
    x = 1; 
else 
    x = 2;
```
假定第一条四元式从地址 `100` 开始编号，写出完整的四元式生成序列，并清晰标明：
1. 每次调用 `makelist()`、`merge()` 的链表内容；
2. 每次调用 `backpatch()` 的回填过程与最终四元式序列。

---

### 【推导过程与执行轨迹】

#### 步骤 1：翻译条件表达式 $a < b$
* 生成四元式 `100: (j<, a, b, 0)`（目标未知，先填0）
  * 建立真链：`E1.truelist = makelist(100) = [100]`
* 生成四元式 `101: (j, _, _, 0)`（假出口）
  * 建立假链：`E1.falselist = makelist(101) = [101]`

#### 步骤 2：处理逻辑与 `&&`
* `&&` 要求如果左侧为真，必须顺延进入右侧测试！
* 此时右侧测试起始地址即为当前行号 `nextquad = 102`。
* 执行回填：`backpatch(E1.truelist, 102)`！四元式 `100` 的目标被填入 `102`。

#### 步骤 3：翻译条件表达式 $c < d$
* 生成四元式 `102: (j<, c, d, 0)`
  * `E2.truelist = makelist(102) = [102]`
* 生成四元式 `103: (j, _, _, 0)`
  * `E2.falselist = makelist(103) = [103]`

#### 步骤 4：合并整体布尔表达式 $E = E_1 \text{ \&\& } E_2$ 的真假链
* 整体为真：即 $E_2$ 为真，`E.truelist = E2.truelist = [102]`
* 整体为假：$E_1$ 为假或者 $E_2$ 为假均导致假，合并两条假链：
  `E.falselist = merge(E1.falselist, E2.falselist) = merge([101], [103]) = [101, 103]`

#### 步骤 5：翻译 Then 分支 `x = 1`
* 此时来到 Then 分支起点，地址为 `nextquad = 104`。
* 执行回填真链：`backpatch(E.truelist, 104)`！四元式 `102` 填入 `104`。
* 生成赋值四元式：
  * `104: (=, 1, _, x)`
* 执行完毕后必须无条件跳过 Else 分支：
  * 生成未定跳：`105: (j, _, _, 0)`，记为 `S1.nextlist = [105]`。

#### 步骤 6：翻译 Else 分支 `x = 2`
* 此时来到 Else 分支起点，地址为 `nextquad = 106`。
* 执行回填假链：`backpatch(E.falselist, 106)`！四元式 `101` 和 `103` 统一被刷成目标地址 `106`！
* 生成赋值四元式：
  * `106: (=, 2, _, x)`

#### 步骤 7：整个 if-else 结束
* 紧随其后的下一条语句地址为 `107`。
* 回填 Then 分支跳出链：`backpatch(S1.nextlist, 107)`！四元式 `105` 填入 `107`。

---

### 【最终四元式代码清单】

```text
100: (j<, a, b, 102)     // E1 真，跳入下一条件判断 c < d
101: (j, _, _, 106)      // E1 假，短路直接跳入 else 分支 (106)
102: (j<, c, d, 104)     // E2 真，跳入 then 分支 (104)
103: (j, _, _, 106)      // E2 假，跳入 else 分支 (106)
104: (=, 1, _, x)        // then 分支：x = 1
105: (j, _, _, 107)      // then 执行完毕，跳过 else 分支
106: (=, 2, _, x)        // else 分支：x = 2
107: ...                 // 后续代码
```

## 6. 代码优化：基本块 DAG 局部优化算法全步骤构建与代码重构

### 【原始题目】
某编译程序生成了如下基本块内的三地址代码序列：
```text
(1) T1 = A + B
(2) T2 = A + B
(3) T3 = T1 * T2
(4) A = C + D
(5) T4 = C + D
(6) E = T3 + T4
```
假定已知该基本块出口处，**只有变量 $A$ 和 $E$ 是活跃的**（其余临时变量均不再使用）。请构造该基本块的 DAG 图，并输出优化重构后的最优三地址码。

---

### 【DAG 逐步构建过程】

* **语句 (1) `T1 = A + B`**：
  * 新建叶子节点 ① 标记为 $A_0$，新建叶子节点 ② 标记为 $B_0$；
  * 新建操作符节点 ③ 标记为 $+$，左孩子为 ①，右孩子为 ②；
  * 将变量 $T_1$ 挂载到节点 ③。
* **语句 (2) `T2 = A + B`**：
  * 寻找操作数：当前 $A$ 对应节点 ①，$B$ 对应节点 ②；
  * 检查图中是否已存在 $+$ 节点且左右孩子为 ① 和 ②？**存在！正是节点 ③！**
  * **触发公共子表达式消除**：直接将变量 $T_2$ 挂载到已有节点 ③ 上，无需新建节点！
* **语句 (3) `T3 = T1 * T2`**：
  * $T_1$ 和 $T_2$ 均指向节点 ③；
  * 新建节点 ④ 标记为 $*$，其左孩子与右孩子均指向节点 ③；
  * 将变量 $T_3$ 挂载到节点 ④。
* **语句 (4) `A = C + D`**：
  * 新建叶子节点 ⑤ 标记为 $C_0$，新建叶子节点 ⑥ 标记为 $D_0$；
  * 新建操作符节点 ⑦ 标记为 $+$，左右孩子为 ⑤ 和 ⑥；
  * **注意**：变量 $A$ 原本挂在叶子 ①（$A_0$）上，此时被重新定值赋值，**必须将变量 $A$ 从节点 ① 撕下，贴到新节点 ⑦ 上！**
* **语句 (5) `T4 = C + D`**：
  * 寻找操作数：$C$ 是 ⑤，$D$ 是 ⑥；
  * 检查发现节点 ⑦ 正好是 $C_0 + D_0$！
  * **触发公共子表达式消除**：直接将变量 $T_4$ 挂载到节点 ⑦ 上。
* **语句 (6) `E = T3 + T4`**：
  * $T_3$ 对应节点 ④，$T_4$ 对应节点 ⑦；
  * 新建操作符节点 ⑧ 标记为 $+$，左孩子为 ④，右孩子为 ⑦；
  * 将变量 $E$ 挂载到节点 ⑧。

---

### 【代码重构与死代码消除】

* 题目给出活跃变量仅为 $A$ 和 $E$；
* 检查各节点上的变量标签：
  * 节点 ③ 算出了 $A+B$，但上面挂的 $T_1, T_2$ 均非出口活跃变量，仅作为中间结果供节点 ④ 使用；
  * 节点 ④ 计算了乘法，挂载 $T_3$，供 ⑧ 使用；
  * 节点 ⑦ 计算了 $C+D$，上面挂着出口活跃变量 $A$；
  * 节点 ⑧ 计算了最终结果，挂载出口活跃变量 $E$。

**重构后的极简三地址码**（从原先 6 条指令锐减为 4 条，消除了 2 次冗余加法！）：
```text
T1 = A + B
T3 = T1 * T1    // 识别出 T2 == T1，直接复用！
A = C + D       // 算一次即供给 A，后续 T4 彻底被消除
E = T3 + A      // 直接用 A 代替 T4 参与计算
```

## 7. 目标代码生成：Chaitin-Briggs 图着色寄存器分配算法完整演算

### 【原始题目】
在一个过程内，经过活跃变量分析后，得到 5 个虚拟变量 $\{v_1, v_2, v_3, v_4, v_5\}$ 之间的冲突图（干扰图）。
假定目标物理 CPU 仅有 **$K = 2$ 个物理寄存器**（颜色为红色 $R_1$ 和绿色 $R_2$）。
冲突图的无向边为：
* $v_1$ 与 $v_2, v_3$ 相连；
* $v_2$ 与 $v_1, v_3, v_4$ 相连；
* $v_3$ 与 $v_1, v_2, v_5$ 相连；
* $v_4$ 与 $v_2, v_5$ 相连；
* $v_5$ 与 $v_3, v_4$ 相连。

请使用 Kempe 启发式化简算法推导演算：该图能否仅用 2 种颜色成功着色？若发生 Spill，请详细说明处理过程。

---

### 【第一阶段：度数统计与 Kempe 化简】

$K = 2$，寻找度数 $< K$（即度数 $< 2$）的节点：
* $\text{deg}(v_1) = 2$
* $\text{deg}(v_2) = 3$
* $\text{deg}(v_3) = 3$
* $\text{deg}(v_4) = 2$
* $\text{deg}(v_5) = 2$

**当前所有节点的度数均 $\ge 2$！找不到任何度数 $< 2$ 的节点！**

---

### 【第二阶段：触发 Spill（溢出）机制】
当所有节点度数均 $\ge K$ 时，无法继续通过 Kempe 规则安全压栈，**必须挑选一个节点牺牲，将其 Spill（溢出）到内存栈帧中**。

* 挑选启发式：挑选冲突度数最高、或者引用频次最低的节点。
* 观察发现 $v_2$ 和 $v_3$ 的度数最高（度数为 3）。假定 $v_2$ 的循环权重较低，**选择 $v_2$ 作为 Spill 候选者**，将其标记并从图中暂时剔除！

---

### 【第三阶段：继续化简】
移除 $v_2$ 后，其余节点的度数更新：
* $\text{deg}(v_1)$ 从 $2 \to 1$（因为删除了与 $v_2$ 的连边）
* $\text{deg}(v_4)$ 从 $2 \to 1$（因为删除了与 $v_2$ 的连边）
* $\text{deg}(v_3)$ 从 $3 \to 2$
* $\text{deg}(v_5) = 2$

此时出现度数 $< 2$ 的安全节点：
1. **弹出 $v_1$（度数 1 < 2）**：压入化简栈 `Stack = [v1]`，从图中移除 $v_1$；
   * 此时 $v_3$ 的度数从 $2 \to 1$！
2. **弹出 $v_3$（度数 1 < 2）**：压入化简栈 `Stack = [v1, v3]`，从图中移除 $v_3$；
   * 此时 $v_5$ 的度数从 $2 \to 1$！
3. **弹出 $v_5$（度数 1 < 2）**：压入化简栈 `Stack = [v1, v3, v5]`，从图中移除 $v_5$；
   * 此时 $v_4$ 的度数从 $1 \to 0$！
4. **弹出 $v_4$（度数 0 < 2）**：压入化简栈 `Stack = [v1, v3, v5, v4]`，图变为空！

---

### 【第四阶段：倒序出栈着色（Select）】

将化简栈依次弹出，进行贪心着色（可用颜色：红 $R_1$、绿 $R_2$）：

1. **弹出 $v_4$**：
   * 当前图中没有邻居，分配 **红 ($R_1$)**。
2. **弹出 $v_5$**：
   * 邻居中只有 $v_4$（红），为其分配不同的颜色：**绿 ($R_2$)**。
3. **弹出 $v_3$**：
   * 邻居中只有 $v_5$（绿），为其分配不同颜色：**红 ($R_1$)**。
4. **弹出 $v_1$**：
   * 邻居中有 $v_3$（红），为其分配不同颜色：**绿 ($R_2$)**。
5. **尝试恢复被标记 Spill 的节点 $v_2$**（Chaitin-Briggs 乐观着色法）：
   * $v_2$ 的邻居包括：$v_1$（绿）、$v_3$（红）、$v_4$（红）。
   * 邻居占用的颜色集合为：$\{\text{红}, \text{绿}\}$。
   * **两门颜色均已被邻居占满，无法为 $v_2$ 分配物理寄存器！**
   * **最终判定**：$v_2$ 确实发生物理溢出，在代码生成时为 $v_2$ 在内存栈帧中分配局部变量槽位，每次使用前后插入 `LOAD` 和 `STORE` 内存访存指令！
